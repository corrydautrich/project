# Campus Life Web Project

## Description & Purpose
This project is a multi-page website for William Jewell College, providing students and visitors with information about campus life. The site includes sections for:
- On-campus events
- Current weather on campus
- Historical facts about the school
- Dining options
- Athletics and upcoming games

The purpose of this project is to practice building a responsive, interactive website using HTML, CSS, and JavaScript while incorporating dynamic content.

## Technologies Used
- HTML5
- CSS3 (with Bootstrap 5.3)
- JavaScript (ES6+)
- Weather API for dynamic weather updates
